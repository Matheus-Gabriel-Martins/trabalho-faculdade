# Help Cat

Projeto acadêmico de uma plataforma para ajudar tutores a encontrar rações adequadas para seus gatos.

## Telas disponíveis

- apresentação pública do projeto;
- login demonstrativo;
- página inicial da área do usuário;
- questionário de recomendação em quatro etapas;
- catálogo com filtros, ordenação e favoritos;
- página de detalhes e informações nutricionais da ração.

## Como executar

O projeto usa somente HTML, CSS e JavaScript. Não é necessário instalar dependências.

1. Abra a pasta `faculdade trabalho` no VS Code.
2. Abra o arquivo `index.html`.
3. Clique em **Open with Live Server**.

Também é possível abrir o `index.html` diretamente no navegador, mas um servidor local evita restrições do navegador durante o desenvolvimento.

## Organização

```text
faculdade trabalho/
├── assets/          # imagens e ícones
├── css/             # estilos separados por tela ou responsabilidade
├── js/              # comportamento, navegação e dados demonstrativos
├── index.html       # página pública inicial
├── login.html
├── home.html
├── questionario.html
├── resultados.html
└── detalhes-racao.html
```

## Observação

Os produtos, preços, autenticação e recomendações são demonstrativos. O projeto ainda não possui backend nem integração com lojas ou provedores de login.
